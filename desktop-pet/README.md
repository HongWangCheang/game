# 森里小企鹅 · 桌面宠物

透明背景、无边框、总在所有软件最前面的小企鹅桌宠（Electron）。不需要打开网站，切到 Google、Pages 或别的软件时它都一直在屏幕上。

画面来自 `../baby_penguin.blend` 的 `Penguin_Walk` / `Penguin_Sit` 动作（Cycles 透明背景渲染，与网站 `dist/assets/pet-*.webp` 相同）。

## 它会做什么

- 平时坐着休息；在网站上学习时在屏幕底部来回走路陪你，碰到屏幕边缘会掉头。
- 点一下：蹦一下并说句鼓励的话。按住拖动：放到屏幕任意位置。
- 只有点在小企鹅身上才会响应，周围透明的地方点击会直接穿透到下面的软件。
- 切换桌面（Space）或别的软件全屏时也在；不占用 Dock。
- 右键小企鹅或点菜单栏里的小企鹅图标：自由散步 / 坐下休息 / 陪我学习（原地走路）/ 回到右下角 / 开机时自动启动 / 退出。

## 和网站同步

App 运行时，在森里网站上点「开始学习」，小企鹅会一直在屏幕底部走路陪你；点「暂停」或结束本次学习，它就坐下休息，直到下次开始学习。网页被关掉、超过 90 秒没有消息时，也会自动坐下。

- 原理：App 在本机 `127.0.0.1:47321` 开一个只接受本机连接的小服务，网站在学习状态变化时（以及学习中每 30 秒）把状态发过来。只接受森里线上网站和本机预览页面（`127.0.0.1` / `localhost` 的任意端口，例如 `4173` 或 VS Code Live Server 的 `5500`）的请求。
- 检测到 App 在运行时，网站不再弹出自己的置顶小窗口，避免出现两只小企鹅。
- 浏览器：Chrome / Edge 第一次可能会询问是否允许网站访问「本地网络」，选「允许」。Safari 可能会拦截网站连接本机，建议用 Chrome。

## 离开检测（摄像头）

在网站上学习时，App 会用摄像头看看你还在不在电脑前：连续 5 秒看不到人脸，小企鹅就停下来做「找你」的动作，并说「你去哪儿啦？」；你回来 1 秒后，它说「欢迎回来！」并继续走路。

- 只在学习中（网站上点了「开始学习」）打开摄像头，暂停、结束学习或没在学习时摄像头关闭（摄像头指示灯也会熄灭）。
- 画面只在本机交给人脸检测模型（MediaPipe BlazeFace，`assets/models/blaze_face_short_range.tflite`），不保存、不上传。
- 第一次使用时 macOS 会询问是否允许摄像头；不小心拒绝了，到「系统设置 → 隐私与安全性 → 摄像头」里打开「Senli Penguin」。
- 不想用时，右键小企鹅或点菜单栏图标，取消勾选「离开检测（学习时用摄像头）」。
- 离开时的新动作：把透明背景序列帧放到 `assets/pet-away.webp`，并在 `renderer.js` 的 `SHEETS.away` 里填上帧数和列数；文件不存在时先用「坐下 + 说话」代替。

## 安装（Mac）

1. 下载对应的压缩包并解压：Apple 芯片（M1–M4）用 `SenliPenguin-1.0.0-arm64-mac.zip`，Intel 芯片用 `SenliPenguin-1.0.0-x64-mac.zip`。
2. 把「Senli Penguin.app」拖进「应用程序」文件夹。
3. 这个 App 没有 Apple 开发者签名，第一次打开前在「终端」运行一次：
   ```bash
   xattr -cr "/Applications/Senli Penguin.app"
   ```
   然后双击打开（或右键 →「打开」）。

## 开发

```bash
cd desktop-pet
npm install
npm start          # 直接运行
npm run dist:mac   # 打包 Apple 芯片和 Intel 两个版本到 release/
```

- `main.js`：透明置顶窗口、点击穿透、拖动、沿屏幕底部移动、菜单栏图标和右键菜单。
- `renderer.js`：序列帧动画和行为（走路 / 坐下休息 / 离开时找你、点击说话、只在不透明像素上接收鼠标）。
- `face.js`：摄像头人脸检测（学习中每 0.5 秒检测一次）。
- 更换画面：替换 `assets/pet-walk.webp`（28 帧，7 列）和 `assets/pet-sit.webp`（60 帧，10 列），每帧 192×192。
